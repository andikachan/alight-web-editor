AM Web

Alight Motion Rendering Engine

A reverse-engineered rendering engine for Alight Motion.

Browser-based runtime untuk memproses preset Alight Motion, dari scene dan layer sampai WebGL effects, audio, easing, timeline, dan video export.

AM Web dibuat untuk rendering, bukan untuk editing. Web ini sejak awal tidak dirancang untuk menggantikan aplikasi Alight Motion atau menjadi editor proyek lengkap. Aplikasi Alight Motion tetap menjadi bagian penting dalam pembuatan dan pengeditan proyek.

AM Web berfokus pada satu hal: mengambil proyek atau preset Alight Motion yang sudah ada, kemudian mereproduksi proses renderingnya dalam lingkungan berbasis browser.
